## What I'm working on

**[Pikki](https://pikki.synthworx.com)** — a live, paid Chrome extension that proves which jobs are real, finds people who can refer you, and applies without inventing facts. Local-first data, on-device models where they fit, a self-updating native helper.

**[Tappi](https://synthworx.com/products#tappi)** — a browser-native AI agent. Tappi indexes the page and gives the model a reference to the element it needs, not a DOM dump. The reference product measured **3–10× fewer tokens** than conventional browser tooling.

**[Kamaloki](https://synthworx.com/work/kamaloki-long-context)** — long-context memory on an 8 GB laptop. A 4B model with a ~28K working context recalled **15/15** planted facts from a **1.1M-token** session at **4.93 GB**, and assembled history **31× faster** than a full re-prefill.

## How I work

- **Diagnose the whole stack.** Data and retrieval, model and inference, orchestration and evals. Most production failures are not prompt problems.
- **Measure before and after.** A baseline agreed in writing, an eval harness on real examples, a cost per request.
- **Ship with guardrails.** Fallbacks, observability, cost caps, and a failure that names itself.
- **Hand off.** Your team keeps the code and the runbooks. No dependency on me to operate it.
